# SnapQuest

SnapQuest is an Android social photo-sharing app built as my Final Year Project (FYP) at Virtual University of Paksitan, CS Department, [2026].

SnapQuest is a mobile app where users will be able to upload only one photo per day, which will encourage creativity and meaningful sharing. SnapQuest will provide secure login to all its users, there will be also community interaction between users through likes and comments, and a personal gallery for each user, powered by Firebase.



## Features

- User signup and login
- Post photos with captions
- Feed with likes and comments
- Search for users and posts
- Trending posts
- Personal profile and photo gallery
- Dashboard
- Reminder notifications (WorkManager)

## Tech Stack

- Language: Java
- IDE: Android Studio
- Backend / Database: [Firebase]
- Libraries: [e.g. Glide, OKHTTP, Material Components, WorkManager]
- Minimum Android version: [e.g. Android 8.0 (API 26)]

## How to Run

1. Clone the repository:
   git clone https://github.com/huzaifakhan42004-droid/SnapQuest-fyp-.git
2. Open the project in Android Studio.
3. Wait for Gradle sync to finish.
4. [If you use Firebase: add your own google-services.json file to the app/ folder.]
5. Connect a phone or start an emulator, then click Run.

## Project Structure

- app/src/main/java: Activities, adapters and models
- app/src/main/res: Layouts, drawables and values
